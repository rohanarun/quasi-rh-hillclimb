# The full count envelope at the critical row

At the critical density `q` of tracker #143 and amplitude `p = 1/2`, its full count envelope equals the marked value `R* = 5/9 + q/6`. Consequently the normalized top margin at the contact height and target `t < θ` with this count is strictly negative, equal to `−(3 + 4q)(θ − t)` in the limiting geometry. This supplies a control for the proposed local change.

The source proves `l = 2129/5000 < q < u = 4259/10000` and the marked crossing identity. The only competing counts in the scheme are the old count and two windows with the same uncapped native count C. Both windows contain this point. Write `v = 5/6 − q`, `v₋ = 5/6 − u` and `v₊ = 5/6 − l`. For the old count let `a = p/(3K)` and `w(a) = 2(1−p)(1−a)/(3−p−2a)`. The numerator of `w(a₁)−w(a₂)` over the product of its denominators is `2(1−p)²(a₂−a₁)`. Thus throughout `K ≥ 7/10` we have `w(5/21) ≤ w ≤ w(0)` at this amplitude. The old count is `1−q + q v w/[2(v+qw)]`. In the positive fraction, lower-bound the numerator by `l v₋ w(5/21)` and upper-bound the denominator by `2(v₊ + u w(0))`. Subtracting the upper bound `5/9 + u/6` for the marked count gives an excess greater than `635023/156031200 > 1/250`. This also covers the target parameter `K = 2t−1` for the proposed rational target. Using `qvU ≥ l v₋ U` and `J ≤ v₊D+u(1−p)A`, its excess over the marked count exceeds `802030500530728243/4450950000039007800000 > 18/100000`. Hence the marked count wins at this row.
